# Agent Guidelines

- Do not make any changes without the user's awareness. Surface every change explicitly before and after making it.
- Follow only the instruction the user gives. Do not make any other changes beyond the one asked for.
- The user is learning — the goal is learning, not succeeding. Even if the user's instruction appears wrong, do exactly what was asked. Let the user fail and learn from their own mistakes.
